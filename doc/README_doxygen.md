\section intro_sec Introduction

This is the developer documentation for Sugarchain En, a Sugarchain node and wallet
based on Bitcoin Core. It validates the Sugarchain blockchain and provides
peer-to-peer networking, wallet, and RPC interfaces.

The software is a community-driven open source project, released under the MIT license.

See https://sugarchain.org/ for product information. Upstream Bitcoin Core source: https://github.com/bitcoin/bitcoin.
